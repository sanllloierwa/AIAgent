引言：为什么需要Transformer

RNN / LSTM：序列建模的主流选择

  • 在 Transformer 出现之前，RNN 和 LSTM 是处理文本、语音等序列数据的主流模型。
  • RNN 每个时间步都依赖前一步的隐状态，形成严格的串行递归计算。
  • 这种逐步计算方式导致训练时难以充分利用 GPU 的并行能力，输入序列越长，等待时间越久。
  • 例如在机器翻译中，RNN 必须逐词处理源语言句子，无法同时计算所有时间步的隐藏状态。
  • LSTM 虽然通过门控单元改善了信息保持，但本质上仍然是逐步递归，训练速度依然受到串行限制。

长序列的梯度消失与信息衰减

  • RNN 在反向传播中需要对梯度进行连续相乘，容易出现梯度消失，使较早时间步几乎无法更新。
  • 当序列变长时，模型会逐步“遗忘”早期信息，难以建立长期依赖关系。
  • LSTM 引入输入门、遗忘门和输出门，在一定程度上缓解了梯度消失，但并没有从根本上解决问题。
  • 当序列长度超过数百个时间步时，即使 LSTM 仍会出现明显的信息衰减。
  • 长文档、长视频和长音频等真实场景，迫切需要一种不依赖逐步递归的序列建模方式。

2014 年：注意力机制进入序列建模

  • 2014 年，Bahdanau 等人将注意力机制引入 Seq2Seq 机器翻译模型。
  • 解码器每一步不再只依赖单一上下文向量，而是动态加权源序列的所有隐状态。
  • 这种机制能够捕捉源语言与目标语言之间的对齐关系，例如英语“the cat”与法语“le chat”的对应。
  • 在长句翻译任务中，注意力显著减少了信息瓶颈，明显提升了翻译质量。
  • 该工作证明了“注意力”思想的有效性，为后来完全基于注意力的架构奠定了基础。

2017：Transformer 的提出与成绩

  • 2017 年，Vaswani 等人在论文《Attention Is All You Need》中正式提出 Transformer。
  • 该模型完全基于注意力机制，去除了循环结构和卷积结构。
  • 在 WMT 2014 英德翻译任务上，Transformer 达到 28.4 BLEU，超过当时最优模型约 2 个 BLEU。
  • 这一成绩说明，仅依靠注意力机制也能达到并超越传统 RNN / LSTM 序列模型的性能。
  • 更重要的是，Transformer 的结构天然适合并行计算，为后续大模型发展提供了关键基础。

核心动机与训练效率

  • Transformer 的核心动机是用可并行的自注意力机制替代 RNN 的串行递归。
  • 模型可以一次性看到整个序列，并直接建模任意两个位置之间的关系，而不必逐步传递隐状态。
  • 这使长距离依赖的信息路径长度变为 O(1)，显著减少了长期依赖中的信息衰减。
  • 论文报告基础版 Transformer 在 8 块 NVIDIA P100 GPU 上训练约 12 小时，即可达到当时最优的英德翻译效果。
  • 与同精度 RNN 模型相比，Transformer 的训练速度快约一个数量级，极大释放了 GPU 并行能力。

Transformer的总体架构与信息流

  • 编码器-解码器堆叠结构：6层编码器与6层解码器，每层含多头注意力、前馈网络与残差连接
  • 输入处理流程：词嵌入（d_model=512）与位置编码逐元素相加，融合词义与位置信息
  • 编码器与解码器内部子层：编码器含两个子层，解码器含三个子层（含掩码自注意力）
  • 前馈网络设计：两层全连接，中间维度2048，ReLU激活，逐位置独立变换
  • 残差连接与层归一化：梯度直通回传，特征维度标准化，稳定深层训练

Transformer的总体架构与信息流

编码器-解码器总体架构

  • Transformer采用经典的编码器-解码器（Encoder-Decoder）结构，编码器负责将输入序列编码为上下文表示，解码器根据编码器输出自回归地生成目标序列。
  • 编码器由6个相同的编码层堆叠而成，解码器同样由6个相同的解码层堆叠而成，层数相同但结构存在差异。
  • 每个编码层内部包含多头自注意力子层和逐位置前馈网络子层；每个解码层则额外增加一个编码器-解码器交叉注意力子层。
  • 所有子层之后均使用残差连接和层归一化，这是深层网络得以有效训练的关键设计，原论文中该架构在WMT英德翻译任务上达到28.4的BLEU分数。
  • 这种堆叠设计使模型能够逐层抽象输入信息：底层捕捉局部语法特征，高层逐渐整合全局语义关系。

输入处理：词嵌入与位置编码

  • 输入文本首先经过词嵌入层（Embedding Layer），将每个离散的token映射为一个稠密的连续向量，维度为d_model = 512。
  • 词嵌入层本质上是一个可学习的查找表，例如词汇表大小为37000时，嵌入矩阵参数量约为37000 × 512 ≈ 1894万参数，在训练中不断更新。
  • 由于Transformer的注意力机制不具有天然的顺序感知能力，需要引入位置编码（Positional Encoding）来注入序列位置信息。
  • 位置编码与词嵌入向量进行逐元素相加，而非拼接，这样可以使模型同时获得词义信息和位置信息，且不改变向量维度。
  • 原论文使用正弦/余弦函数生成位置编码，不同频率对应不同位置尺度，使模型能够泛化到训练中未见过的序列长度。

编码器内部结构详解

  • 编码器的每一层包含两个子层：第一个是多头自注意力子层，第二个是逐位置前馈网络子层。
  • 多头自注意力子层允许每个位置同时关注输入序列中的所有位置，通过8个注意力头并行计算不同类型的关系模式。
  • 每个子层之后都使用残差连接（Residual Connection）和层归一化（Layer Normalization），即输出为LayerNorm(x + Sublayer(x))。
  • 编码器每一层的输入与输出维度始终保持512维不变，这种维度一致性使得6层可以无缝堆叠，无需额外的维度转换层。
  • 随着层数加深，编码器逐步将输入的词嵌入向量转化为富含上下文信息的语义表示，为解码器提供高质量的编码特征。

解码器内部结构与掩码机制

  • 解码器的每一层包含三个子层：掩码多头自注意力、编码器-解码器交叉注意力和前馈网络，比编码器多一个交叉注意力子层。
  • 掩码多头自注意力的核心机制是：在计算注意力分数时，将未来位置的注意力分数设为负无穷（-∞），经过softmax后这些位置的权重趋近于零。
  • 例如在预测第3个词时，模型只能看到第1、2、3个位置的信息，第4个及之后的位置被完全屏蔽，从而保证自回归生成的训练方式与推理方式一致。
  • 交叉注意力子层中，Query来自解码器的自注意力输出，Key和Value来自编码器的最终输出，这使得解码器能够在生成每个词时动态查询编码器提取的源语言信息。
  • 训练时解码器可以并行处理整个目标序列（使用掩码防止信息泄露），而推理时则需要逐词生成，每生成一个词就将其拼接到已生成序列中继续下一步预测。

前馈网络：逐位置的深度变换

  • 前馈网络（Feed-Forward Network, FFN）是一个两层的全连接结构，可以表示为FFN(x) = max(0, xW₁ + b₁)W₂ + b₂。
  • 中间层维度为2048，是输入维度512的4倍；输出层将维度还原为512，保持与输入一致以便残差连接。
  • 中间层使用ReLU激活函数引入非线性变换，使模型能够学习到更复杂的特征组合模式。
  • FFN对每个位置独立进行变换——即不同位置共享相同的权重参数，但各位置之间互不干扰，类似于一个逐位置应用的MLP。
  • 每层的FFN参数量约为512 × 2048 × 2 ≈ 210万，占据了Transformer整体参数量中相当大的比例，是模型容量和表达能力的重要来源。

编码器-解码器信息流

  • 编码器最终输出一个与输入序列长度相同的上下文表示序列，每个位置的向量都融合了其左右两侧的全局上下文信息。
  • 例如输入句子"I love machine learning"经过编码器后，输出3个512维向量，分别对应"I"、"love"和"machine learning"的上下文表示。
  • 解码器通过交叉注意力动态读取编码器输出：在每个生成步骤，解码器根据当前已生成的目标序列，计算对编码器各位置的相关性权重。
  • 交叉注意力使解码器能够在生成每个目标词时灵活聚焦于源序列的不同位置，例如生成"机器"时更关注"machine"，生成"学习"时更关注"learning"。
  • 解码器顶层的输出经过一个线性变换和softmax，在目标词汇表上产生下一个词的概率分布，选取概率最大的词作为当前时间步的生成结果。

残差连接与层归一化

  • 残差连接将子层的输入直接加到输出上，形成x + Sublayer(x)的短路路径，绕过了注意力和前馈子层的变换。
  • 这种短路设计使得梯度在反向传播时可以直接流向前面的层，有效缓解了深层网络（6层编码器+6层解码器）中梯度消失和梯度爆炸的问题。
  • 如果没有残差连接，梯度需要经过多个子层的连乘才能回传到浅层，数值很容易趋近于零或发散，导致训练困难。
  • 层归一化对每个样本的特征维度进行标准化（均值为0、方差为1），然后通过可学习的缩放参数γ和偏移参数β进行仿射变换。
  • 层归一化将每层的激活值控制在稳定的数值范围内，加速了模型收敛，并使训练过程对学习率等超参数的选择更加鲁棒，是Transformer能够大规模训练的重要保障。

核心机制：自注意力与多头注意力

  • 自注意力通过 Q、K、V 三个可学习矩阵将输入映射为查询、键、值
  • 点积注意力流程：缩放、softmax 归一化、对值向量加权求和
  • 多头注意力将 512 维空间拆为 8 个 64 维子空间并行计算
  • 复杂度为 O(n²·d)，但任意两位置信息路径仅为 O(1)

核心机制：自注意力与多头注意力

从输入到 Q、K、V：三个可学习投影

  • 自注意力的第一步是使用三个可学习矩阵 W_Q、W_K、W_V 对每个输入向量进行线性变换，分别得到 Query（查询）、Key（键）、Value（值） 向量。
  • 在原始 Transformer 论文的默认配置中，模型维度 d_model=512，每个头的 d_k=d_v=64；这意味着每个头只在一个 64 维子空间中进行注意力计算。
  • Q 负责“我要找什么”，K 负责“我有什么标签”，V 负责“我实际携带的内容”；三者分工让注意力既能匹配相关性，又能保留原始信息。
  • 例如，当处理句子 “The cat sat on the mat” 时，每个 token 都会得到自己的 Q、K、V 向量，而不是共享同一个表示。

点积注意力：从打分到加权求和

  • 对于某个查询向量 qi，先与所有键向量 kj 做点积，得到原始相关性分数：score(q_i, k_j) = q_i · k_j。
  • 然后除以 √d_k 进行缩放，得到 score / √d_k，防止数值过大。
  • 缩放后的分数通过 softmax 转换为归一化权重：αij = softmax(qi·kj / √d_k)，所有权重之和为 1。
  • 最后用这些权重对值向量进行加权求和：Attention(q_i, K, V) = Σ_j αij vj，输出是一个新的上下文向量。
  • 直观理解：如果某个键与查询高度匹配，其值向量会被赋予更高权重；多个相关位置可以同时被融合，而不是只选一个。

为什么要除以 √d_k？

  • 当 d_k 增大时，点积的方差会线性增长；例如 d_k=64 时，点积结果可能达到较大数值范围，使 softmax 趋于 饱和区。
  • softmax 在输入绝对值很大时，输出会接近 one-hot 分布，梯度变得极小，导致训练不稳定。
  • 除以 √d_k 将方差控制在大约 1 的量级，使梯度保持稳定，是标准操作。
  • 在默认 d_k=64 时，√64 = 8，因此所有点积统一除以 8；这不是随意选择，而是由维度决定的缩放。
  • 这个细节对深层 Transformer 的收敛非常关键，尤其在多头并行训练时能减少数值波动。

多头注意力：拆分、并行计算与拼接

  • 标准 Transformer 使用 h=8 个注意力头，每个头负责一个 64 维子空间：512 = 8 × 64。
  • 实现时不是真的把模型切成 8 份，而是将 Q、K、V 投影矩阵的输出通道分成 8 组，每组独立执行一次缩放点积注意力。
  • 每个头得到 64 维输出，将 8 个头的输出沿特征维度 拼接（concat），恢复为 512 维向量。
  • 最后再乘以输出投影矩阵 W_O，将拼接结果映射回 d_model=512，使信息在不同头之间进一步混合。
  • 公式可写作：MultiHead(Q,K,V) = Concat(head_1,...,head_8) W_O，其中 head_i = Attention(Q W_Qi, K W_Ki, V W_Vi)。

为什么需要多个头：不同子空间中的关系

  • 单头注意力只能在一个表示空间中计算相关性，容易偏向某一种关系模式；多头设计允许模型在 不同的表示子空间 中并行关注不同类型的信息。
  • 例如，某些头可能更关注 相邻词搭配：“cat” 与 “sat” 的局部语法关系。
  • 另一些头可能关注 句法依存：如动词与主语、宾语之间的远距离句法结构。
  • 还有头可能关注 指代关系：例如 “it” 指向前面出现的某个名词，帮助理解代词消解。
  • 这些不同模式无法通过单一注意力权重同时清晰表达，多头机制提供了多个“通道”让模型自己学习分工。

计算复杂度与长序列瓶颈

  • 自注意力的核心是每个查询与所有键之间的两两交互，因此复杂度为 O(n²·d)，其中 n 是序列长度，d 是特征维度。
  • 当序列长度 n 增大时，注意力矩阵大小为 n×n，计算和显存开销呈 平方级增长。
  • 例如，n=512 时注意力矩阵约 26 万个元素；n=2048 时约 419 万个元素；n=4096 时超过 1677 万个元素。
  • 在长文档、高分辨率图像或长时间序列场景中，这成为显著的内存与计算瓶颈，也催生了稀疏注意力、局部窗口、线性注意力等改进方向。
  • 因此，标准自注意力适合中等长度序列，但在超长序列上需要额外策略控制复杂度。

自注意力 vs RNN：长距离依赖的路径长度

  • 在 RNN 中，信息必须按时间步逐层传递：位置 1 的信息要经过 O(n) 步才能到达位置 n，容易产生梯度消失或遗忘。
  • 自注意力中，任意两个位置之间的信息传递路径长度都是 O(1)：每个查询直接与所有键交互，无需逐步传递。
  • 这让 Transformer 能更直接地建模长距离依赖，例如一段话中相距很远的主语和谓语之间的语法一致关系。
  • 代价是失去了 RNN 的线性序列归纳偏置，需要用位置编码补充顺序信息；同时计算复杂度从 RNN 的 O(n·d²) 变为 O(n²·d)。
  • 可总结为：自注意力用更高的计算和内存成本，换取了更强的并行性和更短的信息路径。

位置编码与训练策略

为什么必须显式注入位置编码

  • Transformer 没有循环和卷积结构：输入 token 被并行处理，自注意力计算的是 token 两两之间的相似度，结构本身不提供先后顺序。
  • 如果缺少位置信息，同一批 token 任意打乱顺序会得到完全相同的表示，模型无法区分“A 踩 B”和“B 踩 A”。
  • 因此需要将位置信息显式注入：通常把位置向量与词嵌入相加，再送入编码器或解码器。
  • 这样每个 token 的初始表示同时包含“内容信息”和“位置信息”，后续所有层都能间接利用顺序关系。

原始 Transformer 的正弦/余弦位置编码

  • 对维度 i 和位置 pos，编码使用：
    PE(pos, 2i) = sin(pos / 100002i / d_model)
    PE(pos, 2i+1) = cos(pos / 100002i / d_model)
  • 偶数维使用正弦，奇数维使用余弦；i 从 0 到 d_model/2−1，每个频率对应一对 sin/cos 维度。
  • 波长从 2π 到 10000·2π 按几何级数变化，形成 多尺度时间频率表示：低维编码短距离顺序，高维编码长距离位置。
  • 该方案固定、无额外学习参数，适合不同长度句子，并在早期 Transformer 中被普遍采用。

外推性质：感知相对位置

  • 正弦/余弦编码的关键优势：位置 pos+k 的编码可以表示为位置 pos 编码的线性函数。
  • 例如由三角恒等式：sin(pos+k)=sin(pos)cos(k)+cos(pos)sin(k)，当频率固定时，平移 k 等价于对当前编码做线性变换。
  • 这意味着模型即使遇到比训练序列更长的位置，也能通过已有频率结构进行外推，而不是完全陌生。
  • 通过学习线性组合，注意力层可以更自然地捕捉 token 之间的相对距离，而不只是绝对位置。

Adam 优化器与动态学习率

  • 训练使用 Adam 优化器，结合一阶/二阶矩估计，使训练过程更稳定。
  • 初始学习率按公式动态调整：
    lr = d_model-0.5 · min(step_num-0.5, step_num · warmup_steps-1.5)
  • warmup_steps = 4000：前 4000 步学习率线性上升，避免初期梯度不稳定；之后按 step_num-0.5 逐步衰减。
  • 以 d_model=512 为例，第 4000 步附近学习率峰值约 0.0007，该调度帮助大模型在稳定收敛和充分训练之间取得平衡。

标签平滑：防止对标签过度自信

  • 传统 one-hot 目标会把真实标签概率设为 1，其他所有词为 0，容易驱动模型输出极端分布。
  • 论文将真实标签概率调整为：
    1 − ε + ε / V，其他词的标签概率为 ε / V，其中 ε = 0.1，V 为词表大小。
  • 例如词表 V=37000 时，真实标签约为 0.9000027，其余概率分配给全词表，避免模型对训练标签过度自信。
  • 标签平滑还能缓解过拟合、提高对噪声和同义译法的容忍度，并改善翻译质量。

Dropout 正则化：注意力、残差与嵌入

  • 论文在三个位置使用 Dropout：注意力权重、残差连接输出和嵌入层，论文中 dropout 率统一设为 0.1。
  • 对注意力权重 Dropout 可防止注意力过度集中于少数 token；对残差分支 Dropout 则降低子层之间的共适应风险。
  • 嵌入层 Dropout 使模型不能依赖单一 token 的完整表示，从而提升鲁棒性。
  • 10% 的随机丢弃在大型 Transformer 中起到缓解过拟合、稳定训练的作用。

推理解码：句子对批量训练与束搜索

  • 模型以 句子对 为单位进行批量训练，每个训练样本包含源语言句与目标语言句，适配机器翻译任务。
  • 推理阶段使用 束搜索（beam search）：每步保留概率最高的多个候选序列，而不是贪心选择单个最优 token。
  • 英德翻译中设置束宽 beam_size = 4，在搜索广度和计算开销之间取得平衡。
  • 同时引入长度惩罚系数 α = 0.6，抑制模型只产出过短、安全的翻译。
  • 束搜索与长度惩罚共同作用，使译文在 长度适中、语义完整和概率质量 之间取得更好折中。

代表性变体与跨领域应用案例

  • 编码器/解码器双路线：BERT和GPT系列分别代表双向编码和自回归解码两类主流预训练范式。
  • 视觉扩展：ViT与Swin Transformer将图像分块和窗口注意力机制带入视觉任务。
  • 科学发现：AlphaFold2利用Evoformer模块实现蛋白质结构预测的历史性突破。
  • 落地应用：机器翻译、对话系统和代码生成均体现出Transformer架构的跨领域迁移能力。

代表性变体与跨领域应用案例

BERT：双向编码器预训练的代表

  • 2018年提出：BERT只使用Transformer编码器堆叠，没有解码器，核心优势在于学习深度双向上下文表示。
  • 两个预训练任务：通过掩码语言建模（MLM）随机遮蔽部分输入token进行预测，并通过下一句预测（NSP）判断两个句子是否连续，捕捉词级和句级语义。
  • 刷新11项NLP任务纪录：在GLUE、SQuAD 1.1/2.0、MultiNLI等基准上全面超越此前最优模型，验证了预训练+微调范式的威力。
  • 参数量3.4亿：BERT-Large约3.4亿参数，能有效利用大规模无标注语料，为后续预训练语言模型奠定基础。

GPT系列：自回归解码器与规模扩展

  • 自回归语言建模：GPT使用Transformer解码器，根据前文预测下一个token，训练目标天然适合文本生成任务。
  • GPT-3扩展到1750亿参数：2020年将参数量提升至1750亿，在海量文本上训练后，模型展现出极强的通用性。
  • 少样本学习设置：无需微调，仅通过少量示例或自然语言提示即可完成翻译、问答、摘要等任务，体现强大的语言生成与推理泛化能力。
  • 路线意义：GPT系列验证了解码器架构在规模扩展下的潜力，为后续ChatGPT等对话系统提供了基础模型。

Vision Transformer：图像即Token序列

  • 图像切分为16×16 patch：ViT在2020年将输入图像划分为固定大小patch，并将每个patch线性映射为token向量，类似于NLP中的词向量。
  • 标准Transformer编码器：将patch token与位置编码送入Transformer编码器，通过全局自注意力建模任意patch之间的关系。
  • 大规模预训练：在ImageNet-21k上预训练后迁移到下游任务，在多个图像分类基准上达到与卷积神经网络相当或更好的性能。
  • 跨模态意义：ViT证明Transformer不仅适用于文本，还可作为视觉特征提取器，开启了视觉Transformer研究热潮。

Swin Transformer：移动窗口自注意力

  • 局部窗口注意力：将注意力计算限制在局部窗口内，避免ViT式全局注意力的高计算成本，使模型可扩展到高分辨率图像。
  • 层级结构：通过patch merging逐层合并相邻patch，形成类似CNN的多尺度特征金字塔，更适合目标检测和语义分割等密集预测任务。
  • 移动窗口机制：相邻层之间移动窗口划分，实现跨窗口信息交互，同时保持线性计算复杂度。
  • 当时最优结果：在COCO目标检测和ADE20K语义分割等基准上取得当时最优结果，成为检测和分割领域的主流骨干网络。

AlphaFold2：Transformer驱动的蛋白质结构预测

  • Evoformer模块：AlphaFold2使用Transformer风格的Evoformer处理多序列比对（MSA）和蛋白质氨基酸对表示，提取协同进化信息与结构约束。
  • 原子级精度：在2020年CASP14竞赛中，AlphaFold2将预测误差缩小到接近实验测定水平，被评价为结构生物学领域的重要突破。
  • 预测超过2亿个蛋白质结构：DeepMind与欧洲生物信息学研究所合作，公开超过2亿个蛋白质结构预测结果，覆盖几乎所有已知蛋白质。
  • 跨领域影响：这一成果加速药物设计、酶工程和基础生物学研究，显示Transformer在科学计算中的巨大潜力。

应用：机器翻译与对话系统

  • 机器翻译：Transformer最早在机器翻译任务上验证优势。Google于2018年将Transformer应用于Google Translate，替代此前循环神经网络翻译模型。英德、英法等主要语言对的翻译质量显著提升，尤其在长距离依赖和语序调整上表现更好。
  • 对话系统：OpenAI的ChatGPT基于GPT架构，并通过人类反馈强化学习（RLHF）进行对齐训练。它在2022年底发布后迅速普及，两个月内月活跃用户达到约1亿。ChatGPT能完成多轮对话、内容创作、摘要和问答等开放任务，展示了解码器架构在对话生成上的巨大潜力。
  • 共同趋势：从翻译到开放对话，Transformer统一了序列建模与生成架构，推动NLP进入大模型时代。

应用：代码生成与GitHub Copilot

  • 基于OpenAI Codex：Codex是GPT系列在代码数据上的微调版本，使用Transformer从自然语言注释生成代码片段。
  • GitHub Copilot：集成Codex的编程助手，能够根据函数名、注释和上下文自动补全代码，显著减少重复编码工作。
  • HumanEval评估：Codex在HumanEval基准上可完成约28.8%的Python函数级问题，展示出解决实际编程问题的能力。
  • 行业影响：AI辅助编程由此进入主流，后续代码大模型大多延续Transformer架构。

总结、挑战与未来展望

  • Transformer以自注意力与并行计算重塑序列建模，已成为多领域的基础架构。
  • 二次复杂度仍是核心瓶颈，驱动稀疏、线性、状态空间与IO优化等方向。
  • 长上下文、可解释性与多模态Transformer正在重新定义大模型能力边界。
  • 未来将围绕更高效架构、推理时扩展、世界模型与科学发现持续演进。

总结、挑战与未来展望

Transformer：从序列模型到通用基础架构

自注意力机制可在单层内建立任意位置间的直接依赖，配合并行计算显著提升长程建模与训练效率。相比RNN/LSTM的逐步递归，Transformer缓解了梯度传播困难并更适配GPU并行。

  • 自然语言处理：BERT、GPT等预训练语言模型奠定了大模型范式，在机器翻译、问答等任务上显著提升。
  • 计算机视觉：ViT将图像切割为patch序列，在ImageNet上达到或超过CNN精度。
  • 语音与多模态：Conformer、CLIP、Flamingo等将Transformer扩展到语音识别与视觉-语言对齐。

核心挑战：自注意力的二次复杂度

标准自注意力需要计算所有 token 两两之间的注意力分数，时间和显存复杂度均为 O(N²)。当序列长度 N 增大时，注意力矩阵迅速膨胀。

  • 例如从 4k 扩展到 128k 上下文，注意力矩阵元素量理论上增加约 1024 倍。
  • 长文档、长视频、高分辨率图像和长时间序列都面临显存墙与计算墙。
  • 这限制了大模型在长输入理解、长视频分析和长程时序预测等任务中的可用性。

效率优化：稀疏、线性、状态空间与IO优化

为缓解二次复杂度，研究者提出了多种降低计算与内存占用的策略。

  • 稀疏注意力：Longformer、BigBird 只计算局部窗口与少量全局注意力，将复杂度近似降至 O(N)。
  • 线性注意力：通过核函数改写注意力，避免显式构建 N×N 矩阵。
  • 状态空间模型：Mamba 采用选择性扫描机制，兼顾长序列效率与上下文选择能力。
  • FlashAttention：通过分块计算与重计算，减少 GPU 高带宽内存访问，实现更快的多头注意力。

长上下文竞赛与“中间丢失”问题

长上下文建模已成为大模型竞争焦点，上下文窗口从几万 token 快速扩展到数十万。

  • GPT-4 Turbo 支持 128k token 上下文窗口。
  • Claude 3 支持 200k token 上下文，进一步提升长文档处理能力。
  • 但仅扩大窗口不等于可靠利用：长程信息遗忘和 “lost in the middle” 现象依然存在。
  • 实验显示模型对长上下文开始与结尾的内容利用较好，对中间部分信息提取准确率明显下降。

可解释性：初步理解Transformer内部机制

可解释性研究正逐步揭示Transformer各组件可能承担的功能，但整体仍缺乏统一理论。

  • 注意力头：某些注意力头可对应句法依存关系，如主谓、修饰关系等。
  • 前馈层：研究发现前馈网络可能存储事实知识，例如“巴黎是法国首都”这类三元组。
  • 机理分析：探针、消融和激活分析等工具被用于定位特定知识与行为。
  • 然而，不同任务、层级和头之间的分工仍不清晰，黑箱问题远未解决。

多模态Transformer：统一表示空间与跨模态推理

多模态Transformer将不同模态编码到统一表示空间，推动视觉-语言模型的快速发展。

  • CLIP：通过对比学习对齐图像与文本，在零样本分类和图文检索中表现出色。
  • Flamingo：面向少样本视觉-语言推理，可在少量示例下完成视觉问答与描述。
  • GPT-4V：将视觉输入纳入大语言模型，支持复杂多模态对话与图像理解。
  • 这些模型正在推动图像生成、具身智能、机器人指令理解等方向的演进。

未来展望：架构、推理扩展与世界模型

未来Transformer的发展将不只依赖更大的参数量，而是更高效的架构、更强的记忆与推理能力。

  • 更高效架构：继续探索线性注意力、状态空间模型和混合架构以降低训练与推理成本。
  • 外部记忆增强：通过可读写记忆模块突破固定上下文窗口限制。
  • 推理时计算扩展：在推理阶段投入更多计算进行搜索、验证与自我修正，提升复杂问题解决能力。
  • 世界模型：学习环境动态与因果结构，支撑具身智能、规划与模拟。
  • 科学发现与高性能计算：将Transformer应用于蛋白质结构、材料设计、气候建模等科学问题。
