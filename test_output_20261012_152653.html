一、背景与动机：为什么需要Transformer

  • 传统RNN/LSTM的顺序计算与长距离依赖瓶颈
  • 2014年注意力机制进入神经机器翻译，展现动态检索潜力
  • 卷积序列模型虽然并行，但远距离依赖的堆叠成本过高
  • 2017年Transformer彻底移除循环与卷积，仅靠注意力完成序列建模

一、背景与动机：为什么需要Transformer

传统RNN：顺序计算与并行化难题

RNN的时间步依赖
  • 每个时间步的隐状态 h_t 依赖前一步 h_{t-1}
  • 计算必须沿时间方向串行展开，无法并行
  • 序列长度 N 增加时，训练时间呈线性增长
GPU高效训练的需求
  • 现代深度学习依赖大规模并行矩阵运算
  • 理想模型应能同时处理所有位置
  • 串行瓶颈导致长序列训练严重浪费算力

LSTM/GRU：缓解，但未根治

  • LSTM引入输入门、遗忘门和输出门，通过细胞状态缓解梯度消失
  • GRU以更少的门结构实现相近效果，更新门与重置门平衡旧记忆和新输入
  • 对于数百步以上的依赖，梯度路径仍然很长，模型难以稳定学习
  • 例如长段落建模、长文档问答中，重要信息可能间隔数百甚至上千个词
  • 门控机制可以“减缓遗忘”，但无法并行化，也无法彻底解决长距离依赖

案例：2014年注意力机制进入NMT

背景
早期NMT将整个源句压缩为固定长度向量，长句信息严重丢失
方案
解码器每步动态计算注意力权重，检索编码器相关隐状态
结果
长句翻译质量显著改善，为后续架构奠定基础

卷积序列模型：并行但代价高

优势
  • 卷积可并行计算序列所有位置
  • ByteNet 与 ConvS2S 利用扩张卷积扩大感受野
  • 训练速度明显优于串行RNN
局限
  • 建立远距离依赖需堆叠大量卷积层
  • 依赖距离每增加一段，所需层数快速上升
  • 训练成本随距离增加非线性增长

Transformer：仅靠注意力的序列建模

2017年，Vaswani 等人在《Attention Is All You Need》中提出这一架构。

输入序列
→
多头自注意力并行计算
→
全局依赖加权聚合
→
前馈网络输出表示

完全去除循环与卷积，所有位置同时计算，长距离依赖通过注意力一步建立。

机器翻译验证：更低的训练成本

28.4WMT 2014 英德 BLEU
41.8WMT 2014 英法 BLEU
3.5天8块GPU上的训练时间

以更短训练时间和更低算力成本，超越此前基于RNN和CNN的模型，证明纯注意力架构在大规模序列任务上的可行性。

二、Transformer总体架构：编码器-解码器与数据流

  • 编码器-解码器堆叠：6 层编码器 + 6 层解码器，核心子层包括多头注意力与前馈网络
  • 词嵌入与位置编码：将 token 映射到 512 维向量，并用正弦位置向量补充顺序信息
  • 残差连接与层归一化：每个子层输出为 LayerNorm(x + Sublayer(x))，支撑深层堆叠
  • 解码器输出与概率生成：线性映射到词表大小，softmax 输出下一个 token 分布
  • 训练与推理差异：训练时并行看到完整目标序列，推理时逐词生成并缓存表示

二、Transformer总体架构：编码器-解码器与数据流

Base 配置：关键规模参数

6+6编码器层数 + 解码器层数
512d_model 词嵌入与隐藏维度
约37,000WMT 场景共享词表 token 数

原始论文 base 版本采用 6 个编码器层和 6 个解码器层堆叠；每一层都包含多头注意力、前馈网络、残差连接与层归一化。源语言与目标语言共享同一个词表，在 WMT 翻译任务中约包含 37,000 个 token。

数据流：从 token 到下一个词概率

输入 token
→
词嵌入 + 位置编码
→
编码器×6
→
解码器×6
→
线性 + softmax

输入序列首先经过词嵌入层映射为 d_model=512 维向量；由于模型本身不包含循环或卷积结构，必须为每个位置加入由正弦和余弦函数构造的 512 维位置编码，通过不同频率的波动为每个位置生成唯一顺序信号。编码器并行计算源序列表示，解码器最后将 512 维表示映射到词表大小，经 softmax 得到下一个 token 的概率分布。

编码器子层：残差连接与层归一化

  • 每层两个子层：多头自注意力层和前馈网络层，每个子层后都有残差连接与层归一化。
  • 输出公式：每个子层的输出为 LayerNorm(x + Sublayer(x))，其中 x 是子层输入。
  • 残差路径的作用：将输入直接加到子层输出上，使梯度可以沿恒等路径稳定回传，避免深层网络梯度消失。
  • 支持深层堆叠：正是残差连接 + 层归一化，使 6 层甚至更多层编码器能够有效训练，成为大模型堆叠的基础结构。
  • 归一化位置：原论文采用后归一化，即先做残差加和再进行 LayerNorm，与部分后续大模型采用的前归一化略有不同。

解码器的两种注意力机制

带掩码自注意力
  • 关注目标序列内部 token 之间的关系
  • 掩码限制每个位置只能看到当前及之前内容
  • 保证预测第 t 个词时不泄露未来信息
交叉注意力
  • 关注编码器输出的源序列表示
  • Query 来自解码器，Key/Value 来自编码器
  • 建立源语言与目标语言之间的对齐关系

解码器每个层还包含一个 前馈网络，因此共有三种子层：带掩码自注意力、交叉注意力和前馈网络，每种子层同样配备残差连接与层归一化。

输出层：从 512 维到词表概率

  • 线性变换：解码器最后一层输出 512 维表示，通过线性层映射到词表大小维度。
  • Softmax 概率：对映射结果做 softmax，得到每个词作为下一个 token 的概率分布。
  • 训练损失：训练时使用交叉熵损失，比较预测概率与真实目标 token。
  • 标签平滑：原论文采用 label smoothing，将真实标签概率略低于 1，其他词分配少量概率，防止模型过度自信。
  • 生成策略：推理时依据概率分布采样或贪心选择，逐词生成目标序列。

训练阶段 vs 推理阶段

训练阶段
  • 解码器一次性看到完整目标序列
  • 通过掩码防止未来信息泄露
  • 所有位置并行计算损失
  • 使用 teacher forcing 加速收敛
推理阶段
  • 解码器逐词生成目标序列
  • 已生成 token 的表示被缓存
  • 每步只计算当前 token 的表示
  • 直到输出结束符或达到最大长度

编码器在两种阶段都并行计算源序列表示；差异主要在解码器：训练时并行，推理时自回归生成，并通过缓存已计算表示避免重复计算。

三、核心机制：缩放点积注意力与多头注意力

  • 缩放点积注意力：计算 QKT/√dk，经 softmax 后对 V 加权求和。
  • 缩放原因：避免点积过大导致 softmax 梯度饱和。
  • 多头注意力：8 个并行子空间让模型关注不同表征模式。
  • 长距离依赖：任意位置信息路径为常数 1，优于 RNN 的 n 步。
  • 复杂度 O(n²·d) 与可解释性：注意力权重可可视化分析。

三、核心机制：缩放点积注意力与多头注意力

缩放点积注意力：从查询到加权求和

Attention(Q,K,V)=softmax(QKT/√dk)V

输入 Q、K、V
→
计算点积 QKT
→
除以 √dk
→
softmax 得权重
→
对 V 加权求和
  • 每个查询向量与所有键计算相似度，得到注意力分数。
  • softmax 将分数转换为非负、和为 1 的权重分布。
  • 最终输出是值向量的加权平均，可理解为按相关性提取信息。

为什么必须除以 √dk？

不缩放的风险
  • d_k 较大时，QKT 的方差增大，点积绝对值变大。
  • softmax 输入进入饱和区，输出趋向 0 或 1。
  • 反向传播时梯度极小，训练不稳定甚至难以收敛。
缩放后的效果
  • 点积除以 √d_k，可把方差控制在稳定范围。
  • softmax 输出更平滑，梯度保持有效。
  • 论文默认 d_k=64，缩放是注意力可训练的关键设计。

多头注意力：并行关注不同子空间

  • 多头注意力将 Q、K、V 分别线性投影到多个子空间，而不是只用一组注意力。
  • 原始实现使用 8 个头，每个头维度为 dk=dv=64。
  • 并行计算各头注意力后再拼接，使模型关注不同表征子空间。
Q、K、V 线性投影
→
拆分为 8 个头
→
每头独立计算注意力
→
拼接各头输出
→
再做一次线性变换

长距离依赖：自注意力 vs RNN

RNN 顺序传递
  • 相距 n 步的两个位置，信息需要经过 n 步顺序传播。
  • 链路越长，梯度与信息越容易衰减或丢失。
  • 对长序列的远距离依赖建模较困难。
Transformer 自注意力
  • 任意两个位置之间的信息传递路径长度为 常数 1。
  • 每个位置可以直接读取序列中任意位置的表示。
  • 长距离依赖建模更直接，训练并行度也更高。

注意力机制天然适合翻译、摘要等需要全局上下文的任务。

计算复杂度：短序列高效，长序列昂贵

O(n²·d)每层自注意力复杂度
n×n注意力矩阵规模
平方增长长序列内存与计算开销
  • n 为序列长度，d 为表示维度；注意力分数矩阵为 n×n。
  • 短序列上 GPU 并行计算高效，远距离依赖也可直接建模。
  • 长序列上内存和计算随 n 平方增长，是 Transformer 的主要瓶颈之一。
  • 后续稀疏注意力、线性注意力等方法尝试降低复杂度。

解码器的交叉注意力：有选择地利用源信息

Q 来自解码器当前表示
→
K/V 来自编码器输出
→
计算交叉注意力权重
→
加权聚合源序列信息
→
辅助当前生成决策
  • 与自注意力不同，交叉注意力的查询和键值来自不同模块。
  • 解码器可根据当前生成需求，动态查询源序列中最相关的部分。
  • 在机器翻译中，生成目标词时能自动对齐源句子的关键片段。

注意力可视化：不同头学到不同关系

指代关系
某些头会关注代词对应的实体，例如把“它”连接到前文的“苹果”
句法结构
部分头会重点连接主语、谓语和依存成分，呈现句法树特征
语义关联
另一些头会关注语义相近或相关词，如“医生”与“患者”
  • 注意力权重可以逐层、逐头可视化，并根据输入动态变化。
  • 分析表明不同头可以学到指代、句法结构或语义关联等不同类型的关系。

四、位置编码、前馈网络与正则化策略

  • 前馈网络：2048 维内部 ReLU 变换与位置独立参数共享
  • 正弦位置编码：用三角函数的线性表示能力捕捉相对位置
  • 位置编码比较：可学习嵌入与正弦方案性能接近，后者可外推
  • 正则化：Dropout=0.1 与标签平滑 ε=0.1 的双重约束
  • 规模权衡：base 65M / big 213M 参数量与容量风险

四、位置编码、前馈网络与正则化策略

前馈网络：每个位置上的“1×1卷积”

输入 x
→
Linear(512→2048)
→
ReLU
→
Linear(2048→512)
  • 公式：FFN(x)=max(0,xW₁+b₁)W₂+b₂，内部维度为 2048
  • 每个位置独立计算且参数共享，等价于 核大小为1的卷积层
  • ReLU 引入非线性，使注意力后的表示获得更强的特征交互能力

正弦位置编码：相对位置可线性表示

  • 偶维度用 sine：PE(pos,2i)=sin(pos/10000^(2i/d_model))
  • 奇维度用 cosine：PE(pos,2i+1)=cos(pos/10000^(2i/d_model))
  • 第 i 个维度对应波长从 2π 到 10000·2π，使模型可同时关注短程与长程位置
  • 利用三角恒等式，任意偏移 k 的编码可从原编码 线性表示，有助于建模相对位置
  • 位置编码与词嵌入相加后进入编码器/解码器，不引入额外可学习参数

可学习位置嵌入 vs 正弦位置编码

可学习位置嵌入
  • 随机初始化，随目标任务训练更新
  • 原论文机器翻译性能接近正弦方案
  • 对训练长度外的序列泛化能力较弱
正弦位置编码
  • 由固定三角函数公式直接生成
  • 无需额外位置参数，可外推到更长的序列
  • 通过波长变化编码不同尺度的位置关系

正则化：Dropout 与标签平滑

  • 原论文在残差连接、嵌入层和注意力权重上使用 Dropout=0.1，而不是只作用于 FFN 输出
  • 多个 Dropout 位置共同抑制神经元对特定路径的依赖，缓解过拟合
  • 训练目标使用 标签平滑 ε=0.1：将真实标签概率从 1.0 调整为 0.9，并把剩余 0.1 分配给其他类别
  • 标签平滑防止模型对正确答案过度自信，提高泛化与翻译质量
  • 两种正则化叠加，使深度 Transformer 在大规模训练中保持稳定

模型规模：base 与 big 的容量权衡

训练成本：Transformer vs RNN/CNN

Transformer
  • base：8 块 P100 约 12 小时
  • big：8 块 P100 约 3.5 天
  • 注意力并行，GPU 利用率高
同等性能 RNN/CNN
  • 通常需要更长训练周期
  • 消耗更多计算资源

官方 base 模型在 8 块 NVIDIA P100 GPU 上约 12 小时完成训练；big 模型约 3.5 天。相较之下，达到同等性能的 RNN 或 CNN 模型通常需要更长的训练周期和更多计算资源。RNN 必须逐词展开计算，序列长度一长就会成为瓶颈；CNN 虽可并行，但要捕捉长程依赖往往需要堆叠更多层。Transformer 的全注意力结构因此在训练效率上形成明显优势。

  • 优化器采用 Adam，参数为 β1=0.9、β2=0.98、ε=10⁻⁹。
  • 学习率采用 warmup 策略：前 4000 步线性上升，帮助模型在初期避免太大梯度冲击。
  • 4000 步后按步数平方根倒数递减，使训练后期参数更新更细粒度、更稳定。

批量大小与并行计算

  • 按 token 数设置批量：每个 batch 约包含 25,000 个源 token 和 25,000 个目标 token。
  • 相比按句数组批，按 token 组批能减少不同长度句子带来的 padding 浪费，让 GPU 计算负载更均衡。
  • 大批量使注意力矩阵乘法和前向/反向传播更密集，显著提升 GPU 算力利用率。
  • 梯度更新与多 GPU 并行计算充分利用显存和算力，8 块 P100 上可稳定扩展。
  • 纯注意力并行推理：编码器一次性处理所有位置，推理阶段避免 RNN 式逐词串行生成，更易利用 GPU 并行，整体训练与推理效率显著提高。

  • WMT2014 英德测试集上，Transformer base 获得 27.3 BLEU，big 获得 28.4 BLEU，超过当时最优的递归和卷积集成模型。
  • 英法测试集上，big 模型达到 41.0 BLEU，成为机器翻译任务的新基准。
  • 英法训练成本仅为当时最好模型的约 四分之一，证明高性能未必依赖更大规模串行训练。

消融实验：注意力头与位置编码

有效配置
  • 8 个注意力头效果最佳
  • 保留位置编码
  • 头数与维度合理匹配
修改后的影响
  • 减少头数会损失性能
  • 降低头部维度也导致 BLEU 下降
  • 移除位置编码明显损害结果

消融实验验证了 多头注意力的容量与 位置编码的时序信息对翻译质量都至关重要。8 头设置在表达能力与计算效率之间取得平衡；没有位置编码时，模型只看到无序 token 集合，难以捕捉语序和长程依赖。因此，注意力机制本身并不能天然感知位置，位置编码是纯注意力架构中不可替代的组件。

六、应用生态与未来展望

BERT vs GPT：两种预训练哲学

BERT（编码器）
  • 2018 年提出，利用 Transformer 编码器做双向预训练，同时建模左右上下文。
  • 通过掩码语言模型（MLM）随机遮盖部分 token 进行还原，学习深层双向表征。
  • 配合下一句预测（NSP）判断两个句子是否相邻，增强句间关系建模。
  • 在大规模无标注语料上训练后微调，刷新 11 项 NLP 任务最高水平。
GPT（解码器）
  • 采用 Transformer 解码器做自回归语言建模，从左到右预测下一 token。
  • GPT-2 证明无监督预训练模型可通过零样本方式完成多项任务。
  • GPT-3 以 1750 亿参数展示少样本学习能力，仅靠提示即可泛化到新任务。
  • 奠定后续 ChatGPT 等大规模生成式模型的技术路线。

ViT：Transformer 进入视觉

16×16图像切分为 patch 的尺寸，每个 patch 作为 token 输入
JFT-300M大规模预训练数据集，为 ViT 提供视觉先验
88.55%ImageNet-1K top-1 精度，证明纯 Transformer 可迁移到视觉任务

ViT 直接使用标准 Transformer 编码器处理图像 patch，不再依赖卷积归纳偏置；当预训练数据规模足够大时，注意力机制能够自行学习图像结构。该结果标志着 Transformer 从文本走向视觉领域。

案例：AlphaFold2 与蛋白质结构预测

背景
蛋白质结构预测是生物学长期难题，传统实验方法成本高、周期长，需要从氨基酸序列预测三维坐标。
方案
使用基于注意力的 Evoformer 处理多序列比对（MSA）和残基对关系，迭代更新序列与结构信息。
结果
2020 年 CASP14 竞赛中预测精度中位 GDT 约 92.4 分，接近实验结构精度，成为 AI for Science 的重要里程碑。

从单模态到多模态与决策

  • 语音识别：Conformer、Whisper 等模型将 Transformer 与卷积/CTC 结合，在嘈杂语音和跨语言识别中显著降低词错率。
  • 代码生成：Codex、CodeT5 等基于 Transformer 的代码模型支持从自然语言注释生成可运行代码，辅助开发与测试。
  • 多模态模型：CLIP、DALL·E、Flamingo 等用 Transformer 统一文本与图像表示，实现图文检索、文生图与视觉问答。
  • 强化学习：Decision Transformer、Gato 将决策轨迹视为序列，用自回归目标统一策略学习，展现跨任务控制能力。

效率挑战与高效变体

当前挑战
  • 二次复杂度：原始注意力矩阵随序列长度平方增长，难以处理超长文档或高分辨率序列。
  • KV 缓存内存：自回归推理时为每个 token 缓存 Key/Value，长序列下显存占用很大。
  • 位置外推：训练时未见过的更长位置导致模型长度泛化困难。
高效变体
  • Longformer / BigBird：采用局部窗口、全局注意力和随机注意力，将复杂度降到近似线性。
  • FlashAttention：通过分块和 IO 感知的 CUDA 核减少 HBM 读写，显著加速计算并降低显存。
  • ALiBi、RoPE 等位置方案改善长度外推，支持更长上下文。

未来方向：降低复杂度与深度融合

  • 线性注意力 / 状态空间模型：如 Mamba 等尝试将序列建模复杂度降至线性，提升长序列效率。
  • 稀疏 / 分块注意力：在保持表达能力的同时减少计算，例如 BigBird、Longformer、Reformer 等。
  • 检索增强生成（RAG）：模型在推理时检索外部知识库，降低幻觉并提升事实一致性。
  • 跨模态融合：统一文本、图像、音频、视频和结构化知识的编码空间，实现更通用的基础模型。

目标：在保持建模能力的同时，把计算复杂度从序列长度的平方级逐步降到线性或近似线性。

范式转型：从特征工程到提示

2017以前NLP 依赖任务特定特征工程与浅层模型，各任务需单独设计特征
2018–2019BERT/GPT 提出预训练+微调范式，无标注语料预训练后在目标任务微调
2020+GPT-3 规模扩大，提示学习与少样本替代部分微调，模型即服务兴起

Transformer 的可扩展性使其成为大模型时代最重要的架构基础。
